# Marketing Leads Analysis & CRM Pipeline Insights

## Project Overview

This project demonstrates the analysis of a fictional marketing-lead dataset using Microsoft Excel.

The objective was to analyze lead quality, pipeline status, campaign performance, follow-up activity, ownership, geographic trends and decline reasons, and convert the analysis into actionable business observations.

The dataset contains **2,000 fictional leads** created between January and September 2026.

## Key Areas Analyzed

- Lead pipeline and outcomes
- Campaign performance
- Lead ownership and assignment
- Follow-up activity
- City-wise performance
- Quantity / requirement analysis
- Declined lead analysis
- Decline reasons and reason groups
- Lead ageing
- Data quality and activity gaps

## Key Business Questions

The analysis was designed to answer questions such as:

1. How many leads are currently open?
2. How many leads have converted to opportunities?
3. Which campaigns contribute to the pipeline?
4. Are there leads that remain unassigned?
5. Which leads require follow-up?
6. Which cities generate higher lead volumes or conversion?
7. What are the major reasons for lead decline?
8. Are there potential lead-quality issues?
9. Where are follow-up or ownership gaps visible?
10. Which areas require management attention?

## Business Insights

The analysis converts CRM data into findings and action points rather than focusing only on numerical reporting.

Examples of the areas addressed include:

- Follow-up gaps
- Unassigned leads
- Lead quality issues
- Campaign-level performance
- Geographic patterns
- Decline patterns
